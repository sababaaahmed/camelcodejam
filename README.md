# Camel Code Jam: Holiday Edition

Website for Camel Code Jam, a beginner-friendly holiday hackathon hosted by Girls Who Code at Connecticut College (November 13–15, 2026).

## Files
- `index.html`: the whole website (styles and scripts are inside this file)
- `images/gwc-logo.png`: Girls Who Code Connecticut College logo
- `images/camel.webp`: holiday camel illustration

## Publish with GitHub Pages
1. Create a new public repository and upload all files, keeping the `images` folder.
2. Go to **Settings → Pages**.
3. Under **Source**, choose **Deploy from a branch**, pick `main` and `/ (root)`, then **Save**.
4. After a minute or two, the site is live at `https://<your-username>.github.io/<repo-name>/`.

## Reveal the sub-theme (Friday, 7:30 PM)
1. Open `index.html` on GitHub and click the pencil icon to edit.
2. Search for `EDIT THIS AT 7:30 PM`.
3. Type the sub-theme between the quotes: `var SUBTHEME = "Your sub-theme";`
4. Click **Commit changes**. The site updates within a minute or two.

Until then, the countdown runs on its own. At 7:30 PM it shows "Revealing now" until you add the sub-theme.
